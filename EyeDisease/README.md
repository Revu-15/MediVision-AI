# 👁 Eye Disease Model

This folder contains the retinal disease classification model used by MediVision AI.

---

## Model

**Retinal Disease Classifier**

**Architecture:** EfficientNet-B4

Predicts **45 retinal diseases** from fundus images.

---

## Download

Download the model from Hugging Face:

**[lebiraja/retinal-disease-classifier on Hugging Face](https://huggingface.co/lebiraja/retinal-disease-classifier)**

> Click **"Files and versions"** → Download all files

---

Place all downloaded files inside this folder.
