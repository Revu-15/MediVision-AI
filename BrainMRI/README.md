# 🧠 Brain MRI Model

This folder contains the Brain MRI classification model used by MediVision AI.

---

## Model

**Brain Tumor Classification (MRI)**

The model classifies MRI scans into four categories:

- Glioma Tumor
- Meningioma Tumor
- No Tumor
- Pituitary Tumor

---

## Download

Download the pretrained model from the original repository:

**[Brain Tumor Classification AI Model](https://github.com/ShabGaming/Brain-Tumor-Classification-AI-Model)**

> Go to the repository → Download `model.h5`

---

## Required File

Place `model.h5` inside this folder.
