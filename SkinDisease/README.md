# 🩹 Skin Disease Model

This folder contains the skin lesion classification model used by MediVision AI.

---

## Model

**EfficientNet-B2**

Trained on the **HAM10000** dataset.

Supports **7 skin lesion classes:**

- Melanocytic Nevi
- Melanoma
- Benign Keratosis
- Basal Cell Carcinoma
- Actinic Keratosis
- Vascular Lesions
- Dermatofibroma
